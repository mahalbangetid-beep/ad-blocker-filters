Pengaturan Browser Lock

Belum ada password. Atur password dulu agar browser bisa dikunci.

Aktif / nonaktif

Saat nonaktif, browser tidak dikunci saat dibuka, saat tidak ada aktivitas, saat layar dikunci, maupun lewat shortcut. Password tetap tersimpan, jadi mengaktifkan kembali tidak perlu password baru.

Kunci otomatis

Ganti password

Kode pemulihan

Kode pemulihan bisa membuka browser bila kamu lupa password. Membuat kode baru membuat kode yang lama tidak berlaku.

Simpan kode pemulihan ini di tempat aman. Kode ini hanya ditampilkan sekali dan bisa membuka browser bila kamu lupa password.

Catatan: kunci ini mencegah orang lain memakai browser secara langsung, tapi bukan enkripsi. Agar mode Incognito juga terkunci, aktifkan "Izinkan dalam mode Incognito" di chrome://extensions.
